# 架构说明

Copyright 2026 上海如静知华信息科技有限公司。

ZhuaTech FMS 采用前后端分离的模块化单体。Vue 3 同时承载桌面财务管理端与员工 H5 报销台；Spring Boot 提供认证、资金、往来、预算和费用 API；MySQL 保存业务数据，Flyway 管理结构演进。

```text
浏览器 / 员工 H5
       │ REST + JWT
       ▼
Nginx ─ Spring Security ─ Controller ─ Application Service
                                        │
                 ┌──────────┬───────────┼──────────┐
                 ▼          ▼           ▼          ▼
               资金域     往来域      预算域     费用域
                 └──────────┴──── MySQL / Flyway ──┘
```

领域边界：

- 资金域：银行账户、第三方账户、账面余额、可用余额与账户状态。
- 往来域：客户应收、供应商应付、来源单据、到期日与收付进度。
- 预算域：责任中心、预算科目、年度预算、占用、实际与执行率。
- 费用域：申请人、部门、费用类型、事由、金额与审批状态。

社区源码版优先保持清晰和可运行。企业扩展建议增加组织核算体系、凭证引擎、会计科目、银企直联、电子发票、税务、审批流、消息总线、审计事件、多币种和期间结转。
